# 📈 Bitcoin Price Prediction

This project aims to analyze historical Bitcoin prices and build a predictive model using machine learning. It demonstrates data preprocessing, exploratory data analysis (EDA), and model building to forecast future Bitcoin prices.

## 🚀 Features

- Load and visualize historical Bitcoin price data
- Perform exploratory data analysis (EDA)
- Build and evaluate a regression model
- Predict future Bitcoin prices

## 🧰 Technologies Used

- Python 🐍
- Pandas
- NumPy
- Matplotlib / Seaborn
- Scikit-learn
- Jupyter Notebook

## 📊 Project Overview

1. **Data Loading**: The dataset is imported and basic preprocessing is done.
2. **Visualization**: Various graphs like line plots and histograms are used to understand price trends.
3. **Feature Engineering**: Additional features are extracted to improve model performance.
4. **Modeling**: A machine learning model (like Linear Regression) is trained on the data.
5. **Evaluation**: Metrics such as MAE/MSE/R² Score are used to assess model performance.
6. **Prediction**: Final predictions on unseen data.
